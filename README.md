# Armor Swap

Experimental armour appearance selection for **Ratchet & Clank 2: Going Commando** on OpenRAC.

**Status:** Development. The first native test build is being prepared on the `dev` branch. There is no tested public release yet.

The aim is to change Ratchet's visible armour while preserving the damage reduction and progression of the best purchased armour. See `dev` for the prototype and testing instructions.
